## 🚀 Featured Data Science Projects 🚀 

### 1. Computer Vision: Age Estimation for Retail Compliance Support
Developed a production-ready computer vision pipeline designed to automate customer age estimation, specifically optimized to support cashiers during age-restricted retail sales transactions.
*   **Architecture & Design:** Leveraged a ResNet50 backbone (Transfer Learning pre-trained on ImageNet) integrated with a sequential GlobalAveragePooling2D layer and a single-unit Dense linear regression head.
*   **Data Leakage Prevention:** Built a strict preprocessing pipeline across 7,591 images. Implemented an unaugmented 25% validation split completely isolated from the training slice (augmented with horizontal flips) to guarantee structural data integrity.
*   **Operational Guardrail:** Engineered a business safety-screener threshold set at an estimated age of 25 to actively mitigate the legal compliance risks of false negatives near the 18-year statutory legal limit.
*   **Performance:** Achieved a final validation Mean Absolute Error (MAE) of **5.9241**, comfortably exceeding the strict target threshold requirement of MAE ≤ 8.

### 2. Advanced NLP Sentiment Classification Pipeline
Engineered an enterprise-grade Natural Language Processing pipeline built to process and classify high-volume textual data using parallel statistical and deep transformer architectures.
*   **Feature Engineering & Pipeline Channels:** Deployed dual text-processing pipelines: a sparse frequency-based matrix engineering workflow utilizing TF-IDF with NLTK stopword filters, and a deep contextual sequence tokenization model via PyTorch and HuggingFace BERT-base-uncased.
*   **Model Portfolio:** Trained and evaluated an optimized Logistic Regression linear bypass (designed to minimize framework-specific latency), Multinomial Naive Bayes, a Stratified Dummy baseline, and a tuned `LGBMClassifier`.
*   **Production Safeguards:** Designed and patched a strict mini-batch chunking mechanism to prevent Out-Of-Memory (OOM) cloud infrastructure crashes during high-dimensional BERT inference phases. Eliminated deployment bottlenecks by forcing explicit `.last_hidden_state` object property calls over deprecated sequence mapping slicing.
